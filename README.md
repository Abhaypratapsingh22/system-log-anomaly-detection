# system-log-anomaly-detection
End-to-end anomaly detection system for monitoring system logs using machine learning. Includes data preprocessing, exploratory analysis, Isolation Forest model, and Power BI dashboard for detecting abnormal system behavior.
## Dataset

This project uses the **Logging and Monitoring Anomalies Dataset** from Kaggle.

Dataset Source:
https://www.kaggle.com/datasets/mirzayasirabdullah07/logging-and-monitoring-anomalies-dataset
